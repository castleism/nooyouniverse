Save the live site on Android

  1. Open this page in Chrome on the phone.
  2. Tap ⋮ → Add to Home screen or Install app.
  3. Name it Noo YouNiverse.
  4. Open the new icon. You should get the ship without the Chrome address bar once this PWA is deployed.

That icon is the live website. Waitlist submit only works there. It is not a private notes app and it does not prescribe anything.
